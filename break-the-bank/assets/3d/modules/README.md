# Machine modules

Nothing lives here any more, and that is deliberate.

Hardware bolted onto the machine is built by `ModuleFactory` from the
artifact's effect and its first tag: the effect picks the mechanism — gearing
multiplies, a meter accrues interest, an escapement buys time, a shredder
cancels debt — and the tag picks what it is made of. A new artifact therefore
arrives with hardware that explains it, the moment its `.tres` lands, without
anyone opening the editor.

Two hand-authored scenes used to sit here, for two of the twenty-six artifacts.
The other twenty-four bolted on nothing at all, so most of a run's purchases
were invisible; and once the factory existed, both authored scenes were worse
than what it generated.

`ArtifactDef.module_scene_path` still overrides the factory when it is set. That
seam is for a one-off centrepiece that genuinely cannot be composed from the
vocabulary — not for routine content, which should extend the factory instead so
every artifact sharing that effect benefits.
