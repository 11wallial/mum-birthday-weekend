# Fonts

Three faces, all SIL Open Font License 1.1. The licence text ships beside
them; nothing is fetched at runtime, and the OFL's one hard rule — do not
sell the fonts on their own, keep the notice — is met by this file and the
licences next to it.

| File | Face | Designer | Licence |
| --- | --- | --- | --- |
| `BebasNeue-Regular.ttf` | Bebas Neue | Ryoichi Tsunekawa, Dharma Type | OFL 1.1 (`OFL-BebasNeue.txt`) |
| `IBMPlexSans.ttf` | IBM Plex Sans (variable) | Mike Abbink, Bold Monday, IBM | OFL 1.1 (`OFL-IBMPlex.txt`) |
| `IBMPlexMono-Regular.ttf` | IBM Plex Mono | Mike Abbink, Bold Monday, IBM | OFL 1.1 (`OFL-IBMPlex.txt`) |

Fetched 3 September 2026 from `github.com/google/fonts` (`ofl/bebasneue`,
`ofl/ibmplexsans`, `ofl/ibmplexmono`).

Which face goes where is `scripts/presentation/look/type.gd`.
